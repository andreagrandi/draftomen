---
version: "0.6.5"
date: 2026-10-27
---

- Pool Summary in the TUI and GUI now lists the colour combinations the
  engine weighed: the pairs among the pool's three heaviest colours and, in
  sets with common three-colour decks, their triad. Each row shows its win
  rate, the inferred row is marked, and a triad that was not eligible names
  the reason, such as `black below 20% of the pool`. (#990)
- The profile refresh now rebuilds card data with bonus-sheet cards for the
  sets each run selects, so already published card data gains the cards that
  Scryfall prints under another set. A failed 17Lands ratings fetch leaves
  that set's card data unchanged and is reported for the set. (#943)
- Hosted set profiles now rate bonus-sheet cards, such as Wilds of Eldraine's
  Enchanting Tales, using the committed card data. Scryfall prints these cards
  under another set, so the refresh used to drop their 17Lands ratings. (#944)
- The TUI and GUI now show a three-colour deck with its letters and name,
  such as `UBG Sultai`, wherever they show the inferred or built colour pair.
  Two-colour pairs look as before. The PRD and README describe three-colour
  decks and the 10% share threshold. (#981)
- The deck builder now considers the ten three-colour decks next to the ten
  pairs in sets where those decks are common. A three-colour deck qualifies
  only when each colour holds a fifth of the top spells and the pool has at
  least three dual lands, tri-lands or multicolour mana sources. It gets a
  three-colour mana base and no splash. (#980)
- Pick recommendations now treat a balanced three-colour pool as a
  three-colour deck, such as UBG, in sets where those decks are common. The
  engine does this only after pick 5, when the deck's win rate beats the
  heaviest two-colour pair and each colour holds at least a fifth of the pool
  weight. Small 17Lands samples are pulled toward the set's average
  three-colour win rate. A three-colour deck gets no splash. (#979)
- Hosted set profiles now carry a win rate for each three-colour deck without
  a splash and the share of games those decks played, in the new top-level
  `triad_profiles` and `three_color_share` keys. Small samples are pulled
  toward the set's average three-colour win rate. The schema stays at
  version 4, and released clients load these profiles without downloading
  them again. (#978)
- The 17Lands cache now keeps win rates for the ten three-colour decks without
  a splash, and the share of games those decks played. Caches written by
  earlier versions still load, with no three-colour data. (#977)
- Bonus-sheet cards such as Enchanting Tales in Wilds of Eldraine packs are no
  longer shown as unknown cards. `export-set-data SET` now adds them from the
  17Lands card ratings. (#942)
- The Microsoft Store build asks the Store for updates instead of the website,
  so Store users no longer see an update before the Store has it. The update
  dialog shows only the download link for how Draft Omen was installed:
  the Store listing, the GitHub releases page or the website. (#932)
- Dependabot groups its updates into one pull request per ecosystem and waits
  7 days after a release before proposing a new version. It now also covers
  the npm dependencies in `website/` and `extensions/`.
